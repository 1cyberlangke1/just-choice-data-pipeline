# docs/ —— 对外文档

这个目录里的东西是给**仓库外面的人**看的：数据格式、工作流目录、调研笔记。
项目的入口在仓库根的 [README.md](../README.md)。

| 文档 | 是什么 |
|---|---|
| [数据格式.md](数据格式.md) | JSONL 契约：顶层字段、三种题型、编号口径、怎么校验 |
| [工作流清单.md](工作流清单.md) | 51 个 workflow 逐家一行：覆盖什么 case、要不要后端、题型、题族、规模 |
| [JEV生态与开源复现调研.md](JEV生态与开源复现调研.md) | JEV 是什么、有哪些开源复现、别人怎么可靠合成数据 |
| [JEV场景覆盖地图.md](JEV场景覆盖地图.md) | 社区用例清单按场景簇归堆，与本仓库的覆盖情况对齐 |
| [黑盒API合成数据范式调研.md](黑盒API合成数据范式调研.md) | 用在线黑盒 API 批量合成选择题数据的范式与坑 |

## 维护者笔记不在这里

另有一套**内部工作笔记**（逐份产物的质量体检、答案分布均衡账、文本多样性度量、逐条人工抽检、
合成过程账、代码重复度、当前进度），放在 `docs_local/`，**不入库**——跟 `tmp/` 一样只在维护者
本机，随每次生成重算。它带内部脚本口径与逐条归属，不适合当对外文档读，所以不随仓库分发。

那套笔记由 `tmp/` 下的生成脚本现算，每份文档头部都写了怎么重跑。
